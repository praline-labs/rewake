# The archive

History that no session needs to read to work on rewake now, kept for the record. Moved here
on October 18, 2026 with `git mv`, bytes unchanged, by the owner's decision of that day
([its entry](../roadmap/2026-10-18-decision.md)). An archived document is not edited; its
links stay as they were written, from the directory it left, so one may point to a path that
is no longer there — git history has it.

- `1.x/` — the documents of the 1.x code stage 3 removed, the former `docs/archive-1.x/`, with
  its own table of where each was ([1.x/README.md](1.x/README.md)).
- `v2/` — the closed stages of 2.0: the revision of 1.x, stage 3's plans, tests and
  evidence, the design of the documents' tests, the Codex design, stage 4's audit and its
  readings of Codex and agent-deck. Stage 3's documents that living ones still cite —
  `stage3-fixture`, `stage3-state`, `stage3-decision` — stay in `docs/v2/`; `stage3-upgrade` joined the archive when the clearing of 1.x left the code.
- This folder — the records and research of 1.x: Codex's research and protocol, the gateway
  and native mailbox evidence, the thread probes, the review rounds, the work queue, the
  transport milestones, the Claude Code parity runs, the harness feature map of September,
  the check-runner proposal and its scenarios, the intermittent bugs, and the roadmap's
  remaining work of September ([roadmap-remaining-2026-09.md](roadmap-remaining-2026-09.md)).

The documents of grants and of the mail tool — `grants*.md`, `git-grants.md`,
`mail-bridge*.md`, `research-mail-tool.md`, the tool and channel rules (`rules-tools.md`,
`rules-channel.md`) and the tool cases of the workflow suite (`testing-tools.md`) — moved
here with their code on October 18, 2026.
