## Review: accepted

One round, no findings. The review compared every changed Go file of the preparation token
by token — the renamed locals and their quoted mutation text, the gate's package clause, the
imports under their 2.0 names (the stripped binaries before and after them hashed equal,
plain and with the fixture), the review files renamed with their functions only — and the
move file by file, with its 24 mutations, build values, layout tables, rule paths and
documents. The import graph, taken in all four build variants, shows no `core` package
reaching `host` or `tool`, no `tool` package reaching `host`, and no `host` package reaching
an adapter other than the API package.
