# The pi adapter

October 18, 2026, by the owner's decision that pi is the next harness. **Done.** `rewake pi`: an
embedded extension speaks JSON lines over the run's socket, its peer checked by `SO_PEERCRED`;
wake and steering, turn reports with the last assistant text, a conversation by `--session-id`;
telemetry (context, model, thinking level), compaction with a focus, and an interrupt read as
stopped. Minimum pi 1.2.0; 1.3.0 read as compatible (identical extension declarations). Built on
the Codex side, wire contract tests; live on a real model every scenario passed
([research-pi.md](../research-pi.md#live-acceptance-on-a-real-model-october-18-2026)). **Open.**
pi in the space, a read-only reviewer profile.
