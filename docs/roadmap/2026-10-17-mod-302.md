# The Claude Code mod on Claude Code 2.1.302

October 17, 2026. Claude Code on the machine went from 2.1.296 to 2.1.302 and the `mods` skill
was republished from it; decided by the owner the same day: bring the mod up to it before S4-7.

**Found.** One change touches the mod: from 2.1.299 `turn.start` is raised for a subagent's
turns too, and the mod sent each as a `turn/start` of the session. Found by the writer's audit
and, independently, by the reading on the Codex side; harmless so far, since the host keeps no
untimed start, but outside the session-only boundary of rule O2. Nothing else in the release's
report touches the three hooks, the `$` calls or the tests' meaning.

**Done.** The mod sends only a start without `agentId`, held by a test with a child's start and
end beside a main pair; the helpers keep their `Host` of closures (classes, testability, and
the minimum version below 2.1.299); the live script's reload writes a real change, since a save
of the same bytes no longer reloads. Five checks green on `34c23d7`; `claude plugin test` 32
pass. Live on 2.1.302 every scenario of S4-6's part C passed
([the record](../research-claude-mod.md#the-mod-on-claude-code-21302)).

**Open.** A standalone foreground `sleep` is refused on this build and the worker moves it to
the background with `rewake pending`; nothing to change in rewake. What the release offers the
space — `turn.start` of the keeper, `resume` on `agent.spawn`, `$.ui.view({ agentId })`,
`prompt.change`, `Input.rows` — is for S4-7's design, each behind a probe.
