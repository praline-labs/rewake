# rewake 1.0.0 on npm

On September 28, 2026, on the owner's word, rewake 1.0.0 was published to the public npm
registry under the organization's scope: `@praline-labs/rewake`, with
`@praline-labs/rewake-linux-x64` and `@praline-labs/rewake-linux-arm64`. The release commit
`6aacced` sets the source's version; the tag `v1.0.0` points at it.

## How it went

- The release gate ([install.md](../install.md#releasing-to-npm)) ran on the pushed release
  commit: every check before the build and after it passed, then the platform packages and
  the entry were uploaded in that order.
- Right after the upload the registry did not show them yet, so the gate exited 1 and asked
  to look again rather than calling it a success. A bounded wait later all three versions
  and the entry's `latest` read 1.0.0; the tag was pushed after that.
- An install from the registry into an empty prefix ran `rewake 1.0.0 · build 6aacced`.
