# The host mode: the pane removed, step 1 built

October 18, 2026, by the owner's decision: the workers' pane, `/workers`, the `workers/*`
endpoints, the Raster cells and `rewake attach` removed, the panel's design archived. Then step 1
of [the host mode](../v2/host-mode.md): `rewake --host --main <harness>` runs main on the host's
pseudo-terminal, a tab per space from its view, a bar, Ctrl+\ n/p/digit/m, keys to the shown
program, its input modes mirrored, indexed colors kept as indices, resize and a restored exit.
Checked live on Claude Code 2.1.302 with the cheapest model, and by the `fixture-host` scenario.
Found live: OSC strings lost to a 0x9C byte in the emulator library, filtered in the grid.
Open: steps 2–4 (mouse and paste, the sidebar, events and colors), the review, acceptance.
