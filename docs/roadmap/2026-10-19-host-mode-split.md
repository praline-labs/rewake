# The host mode: the split

October 19, 2026, by the owner's decision in place of step 3's sidebar of status cards
(the host mode, step 5): from 120 columns main takes the left part and the
chosen worker the right, a divider between, each program's pty sized to its part. The bar chooses
the worker and focuses it; a click in a part or Ctrl+\ ← → moves the focus, which the keys, the
modes, the title and the cursor follow; mouse events go to the program under the pointer, a drag
staying with the one it began in; Ctrl+\ z zooms; below 120 columns the bar switches the whole
window. A worker in a turn is marked on its tab. Checked live on Claude Code 2.1.302. Open: a
`[host]` configuration of the proportion, the owner's own terminal, the review, acceptance.
