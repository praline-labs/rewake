# Stage 3 of 2.0: S12 accepted

S12 is the twelfth step of stage 3 ([stage3.md](../v2/stage3.md)): the `infra` moves
([stage3-moves.md](../v2/stage3-moves.md#s12-infra-moves), the places from
[stage3-packages.md](../v2/stage3-packages.md)). It was built on October 11, 2026, on
branch `s3-s12` from `eccaf13`, in one move, `e6b2d20`, and this entry, and accepted in review the same day; the step
needs no acceptance on the Codex side.

## The inventory

Taken with `go/types` before the move (`golang.org/x/tools/go/packages`, tests
included): the `Uses` of every identifier in every package of the module, over the four
build variants — no tag, `rewakefault`, `rewakefixture`, both — and every string literal
outside the import declarations. What the step expected, and what it found:

- **They import only the standard library and each other.** Confirmed: the one edge
  between them is `state` to `boottime` (`boottime.Now` in `reach.go` and
  `reach_test.go`), the edge correction 1 of [stage3.md](../v2/stage3.md) allows. Their
  tests reach nothing else either, so each test moves whole with its package.
- **Every other package imports them.** Not literally: they are imported by `cli`,
  `inbox`, `wrap`, `registry`, `receipt`, `sessionstate`, `control`, `grant`,
  `grantauth` and its test helper, `brief`, `worktree`, `bridge/endpoint`,
  `host/launch`, the two adapters, `test/toolrig` and `test/workflow`; `cmd/rewake`,
  `tools/`, `adapter`, `adapter/catalog`, `alias`, `bridge`, `channel`, `role` and
  `registrytest` import none of them. What the move rests on holds: nothing they import
  is outside `infra`, so none of their consumers reaches back.
- **No mutation and no build value names them.** Confirmed: no string literal in the
  module names one of their paths or files — the suite's mutations name files in other
  packages, and the `-X` values name variables of `inbox`, `cli` and `wrap`, which call
  `buildtime.Duration` but are not in it. The only string consumers were the four
  entries of the layout test's transition table.

No row needed more than an import path changed, so there is no preparatory commit.

## The move

`git mv` of the four directories to `internal/infra/`; the package clauses stay. Every
file is a rename at 96–100% similarity: 23 at 100%, and `state/lock_test.go`,
`state/reach.go`, `state/reach_test.go` at 96–97% for their changed import line. The
import paths in 278 files, sorted again where the new path changes their order; the
four transition entries out of `internal/layout_tables_test.go`; the tree of
[code.md](../code.md); the paths in the living documents — among them the test paths
[rules/effects.md](../rules/effects.md) names — and in two comments. The dated records
of the roadmap and the revision table of [revision.md](../v2/revision.md) keep the paths
they were written against.

## Review: accepted

One round, no findings. The review compared every changed file of the move against the
tree before it, allowing only the four import paths, the order of import blocks, the two
comments and the paths in documents: 303 Go files and the documents matched, and the one
other change was the four transition entries leaving `internal/layout_tables_test.go`.
It read the inventory's tool and its output over the four variants, and checked by hand
what the tool cannot see — a path built by concatenation or a format, the `-X` values
the suite builds, the release script, the mutations' file paths and non-Go text — and
found no other consumer of an old path. The literal scan alone is no proof for a later
move whose paths are computed; there the same hand check is owed.
