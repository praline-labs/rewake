# The worker's settings as a file, migrated on launch

October 19, 2026, step 4 of [the worker profile](../v2/worker-profile.md), by the owner's
decision of that day. **Done.** A Claude Code worker's `--settings` is the service folder's
`settings.json`: rewake writes its defaults there marked `"rewake": {"defaults": 1}`; a newer
build adds only the steps after the file's version, a retired one taken out only where it still
holds rewake's value. `rewake.keep` and the merge are gone. A file that does not parse, a key a
default owns holding another kind, or a link to nothing refuses the launch, the file untouched.
Live with haiku: the owner's `{}` gets every default, `Agent` taken out comes back.
**Open.** The check of the review's two blocker fixes (a dangling link, a wrong-typed key).
