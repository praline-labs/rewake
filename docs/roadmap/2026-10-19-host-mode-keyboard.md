# The host mode: the keyboard protocols mirrored

October 19, 2026, found live by the owner: inside the host Shift+Enter reached Claude Code as a
plain Enter and sent the message, since no emulator answered its kitty query and the person's
terminal was never asked for the protocol. Every emulator now keeps the kitty keyboard flags and
the modifyOtherKeys level and answers `CSI ? u`; the canvas pushes the shown program's flags as
one entry over the terminal's own and sets its level, changed at a switch, popped and reset at the
exit and on signals; the prefix is read in the CSI u forms with locks and event types, releases
never cancelling it. Checked live on Claude Code 2.1.302 and pi 1.2.0 through a script terminal.
Open: a real terminal's Shift+Enter seen by the owner, steps 3–4, review, acceptance.
