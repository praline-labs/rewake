# The strip under each worker pane

October 21, 2026, on main's decisions ([shell.md](../v2/shell.md#the-strip)). **Done.**
The shell draws each worker pane's last row: name and type, activity, branch, model and effort, context
filled, used and window; too long, it leaves out the model, then the branch. Data from `rewake list --json`
asked as main's run, found by the wrapper's pid, and `space list`'s checkout branch, else `git`; no Go change.
The Claude Code mod samples after each main-loop step, so a long turn's fill no longer waits for the heartbeat.
Live with the cheapest model and pi on a stub model: wide, 100 and 52 columns, idle and working, the branch
switching to the entered checkout's. Open: the type part not seen live (the test aliases had none); colours not
read back from the stand-in terminal.
