## The first review round

The archive, the deletions, the channel cut, the version read, the grant stub and keeping
`--grant-git` were accepted. Changes required:

- **R1 (high).** The worktree scenario and its eleven controls left with the Codex
  column, though every control mutates surviving code: `cli/launch_worktree.go`,
  `worktree_keep.go`, `worktree_land.go` and `internal/worktree`.
- **R2 (high).** The grant forgery scenario and its three controls left the same way,
  mutating `grantauth` and `wrap/grants.go`. The grant-dir scenario's own three controls
  mutated the Codex adapter and are adapter-specific; its neutral promise — registration,
  the recheck at delivery, the sender told, the authority's lifetime — had no workflow
  oracle left.
- **R3 (medium).** `tools/standin` still answered with the removed MCP tool.
- **R4 (low).** The archive's README linked a missing path and gave the wrong reason for
  not building the archive.
- **Code only tests reach.** Each kept piece had to name the step that closes it.
- **The resumed-reader oracle.** The report said it had no neutral home; it has a partial
  one in `test/toolrig/answer_bound_test.go`, and the MCP reply queue it also checked does
  not apply to a transport with one reply per connection.
